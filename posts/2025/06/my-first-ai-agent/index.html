My First AI Agent

June 17, 2025

Following the video I developed my first AI agent. it includes four modules on the website make and google cloud plateform .

The make offer the senarios where the modules representing the APP can be added and configured. The app invovoled Gemini and Gmail. Google product can give me the API to leverage the application. google ai studio offers the API key to allow I use the system on the plateform. google cloud plateform ( it is a product like microsoft Azure and Amazon Cloud service) offers the API of Gmail. So we can automatically write the email and gmail.

这种工作流程可以方便生成简报和报告，方便人们去使用。

in the process, the tricky part for the first time is to set up the cloud plateform to get the Authentic Name and Key ID and Secret, which are the two important part to authorize the make to have access the gmail system.

The other hard part is the Prompt to feed into the Gemini - the logic and precise descriptions on the probelm using natural language. The function/action we would like to assigne the robot to do, and the format control we desire for the systems.

the third hard part is the operation on the cloud plateform. the plateform is a big system and unfriendly to the newcomeers.
