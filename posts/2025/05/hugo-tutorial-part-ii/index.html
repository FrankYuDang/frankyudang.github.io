2 How to insert image

The image should added to the folder location /your-web-site-name/static/ . Notice there should style.css in the folder too. Below command should be used to add the style.css.

cp themes/lugo/static/style.css static/

But in my case of contrast-hugo, I don’t have the file. Instead, I copy the index.css and minimal.css file into the folder. I put the figure pic.png into the folder. The reference command for images goes like below

![my image](/pic.png)
**< img link="https://frankyudang.github.io" caption="This is a caption." src="/pic.png"  mouse="This is what appears if your mouse over the image" >**  ## replace ** with {{ }}

3. understand the folder structure?

y ou can edit frankyudang/archetypes/default.md, and this file is assoicated with the new post. We can edit draft=false

In the frankyudang/content/posts, you can add new posts using the comand

hugo new posts/POST_NAME.md

Actually, frankyudang/ folder is created by the command

hugo new site frankyudang

After that, the desired theme is git clone into the the folder using the below command

cd frankyudang
git clone https://github.com/lukesmithxyz/lugo themes/lugo

The above commend will add the downloaded theme into the /frankyudang/themes/ folder. Inside this folder,

|- archetypes
|- layouts  # this is empty, I put the themes/lugo/layout/shortcodes into this folder
|- static
|- config.tmol
|- README.md
