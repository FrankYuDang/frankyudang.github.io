Computer literacy shortcuts for windows

May 06, 2025

Using shortcuts can boost the productivity and efficiency of our work. Below is the summary of shortcuts I found useful.

Win+Tab Task view. It allows you quickly swithch between tasks and mange different workspace effectively. For example email and clander on Desktop 1, current project on Desktop 2, personal browsing on Desktop 3.

Alt+Tab Switch between applications.

Win+D Show desktop and press the combination again will restore all the windows.

Win+E open the explore folder

Win + shift + S Snip and sketch

Ctrl+Shift+Esc Open task manager.

ctrl+L edit the address bar

Start by incorporating one or two and gradually add more as they become second nature.
