Manage figure with Hugo -Part III

May 11, 2025

hello, in this post demonstrating how to manage image. There are two ways to store and reference images in HUgo

  1. global figure, stored in the /static/image/folder
  2. local figure, stored in the same folder as /posts/xxx-post/xxx.md

Global figure

The folder strutcutre is like this:

your-hugo-site/
├── archetypes/
├── content/
├── data/
├── layouts/
├── static/
│   └── images/  <-- 在这里存放图片
│       ├── logo.png
│       └── my-global-image.jpg
├── themes/
│   └── contrast-hugo/
└── hugo.toml (或 config.toml)

The command syntax is below：

![这是图片的描述文字](/images/my-global-image.jpg)
<img src="/images/my-global-image.jpg" alt="这是图片的描述文字">

Local figure (page bundles)

The folder structure is below

your-hugo-site/
├── content/
│   └── posts/
│       ├── my-first-post/  <-- 这是一个 Page Bundle
│       │   ├── index.md         <-- 文章内容
│       │   └── featured-image.jpg <-- 文章专属图片
│       │   └── another-image.png
│       └── my-second-post.md  <-- 这是一个独立的 Markdown 文件 (不是 Page Bundle)
├── static/
└── ...

The reference method

One is Markdown syntax

![文章的特色图片](featured-image.jpg)
![另一张图片](another-image.png)

The other one is Hugo html

beautiful flower** < figure src="featured-image.jpg" title="beautiful flower" >** # replace ** with {{}}
