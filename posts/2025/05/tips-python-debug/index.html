一键调试

In vs code,

·F9：add the breakpoint and edit the break point by inserting expression or hit count.

F5 或者 debug with python ,启动调试器，显示调试类型列表

F10 is to run the code to next line

调试视图查看代码相关的信息变量

debug console 对变量和表达式进行运算

创建调试

在调试视图,单击 create a launch.json file, 选择 python file 选项

"name" = "Python: Current File" # 调试配置的名字
"program" = "{$file}" # 当前活跃文件
"cwd" = ${workspaceFolder} # 指定调试器的工作目录，打开文件夹的完整路径
