Build a blog using Hugo and Github in 10 min

May 05, 2025

I follow this straightforward youtube video by Ryan Schachte to build my blog. Below is a summar of the procedure and som caveats. I developed on Windows system.

Steps to build a blog

step 0: run the Windows PowerShell as administration, and conduct and check the installment of Git, Go and SaSS. There three softwares are prerequisits for the following steps. Notice: follow each webpage to install these gadgets, and the internet connetion may be bad, slow the process. I stuck at fetching the Dart denpendancies ... . Then I change the wifi to my phone hotspot. After that it works.

PS C:\WINDOWS\system32> sass --version
1.87.0
PS C:\WINDOWS\system32> git --version
git version 2.46.0.windows.1
PS C:\WINDOWS\system32> go version
go version go1.24.2 windows/amd64

step 1 install Hugo on windows. there are two small steps, which are prebuilt binaries and package managers .

PS C:\WINDOWS\system32> choco install hugo-extended
PS C:\WINDOWS\system32> hugo version
hugo v0.147.1-95666fc5a4fd2d87528a1a69d562e0538a97062a+extended windows/amd64 BuildDate=2025-05-01T13:50:04Z VendorInfo=gohugoio

step 2: Create 2 repos, one is named blog and the other one is named yourusername.github.io. The latter one naming method is requried by the github, which will automatically treat this repo differently. In my case, the latter one is named after frankyudang.github.io

blog repo is for storing the code

frankyudang.github.io for production repo where we deploy the form.

The above two repo is simplly created without any further actions.

step 3 Choose the theme - we choose contrast-hugo, which you will fint it here

step 4 Clone the blog repo locally. Notice: (1) you have to know the basics of git. (2) the fold strucutre should be like below.

cd C:\Document\Blog> 
git clone https://github.com/FrankYuDang/blog.git

Blog
├── blog

step 5: move into the blog folder to use hugo creating new site, and then the folder structure is like below

hugo new site frankyudang

Blog
├── blog
  ├── frankyudang
    ├── archetypes/
    ├── assets/
    ├── data/
    ├── i18n/
    ├── layouts/
    ├── static/
    ├── themes/
    ├── .hugo_build.lock
    └── hugo.toml

step 6: move into the \blog\frankyudang\themes\ folder and clone the desired theme into this folder

git clone https://github.com/niklasbuschmann/contrast-hugo.git

step 7: in order to use this theme, set this theme as default. We should edit the file \blog\frankyudang\hugo.toml as below. we modeifed the baseURL and add the theme

baseURL = 'https://frankyudang.github.io/'
languageCode = 'en-us'
title = 'Frank-YD Site'
theme="contrast-hugo"

step 8: go back to the \blog\frankyudang to run the code

hugo server

and gives you a link http://localhost:1313/

step 9： create a new post. POSTNAME could be replaced with your prefered name. And this will create a folder contents\post\ where it stores the POSTNAME.md.

hugo new posts/POSTNAME.md

And now you can edit this POSTNAME.md using editors. (I use vs code)

step 10 add our other blog (frankyudang.github.io) as a submodule. This allows us to store the static assets that were generated in a seperate repo. It is a good way to organize your code. This will create the folder strcuture as below.

Notice: make sure main branch is located in the repo. otherwise you need to create one.

cd .. # back to the Blog\
git clone https://github.com/FrankYuDang/frankyudang.github.io.git 
cd (
git chceckout -b main (not necessary)
touch README.md # creae a new,empty file. I did it manually

git add .
git commit -m "adding readme"
git push origin main

Blog
├── blog
  ├── frankyudang
    ├── archetypes/
        ···
        ···
    └── hugo.toml
├── frankyudang.github.io

setp 11 （IMPORTANT） we deploy a submodule into the public folder.

cd \Blog\blog\frankyudang\
git submodule add -b main https://github.com/FrankYuDang/frankyudang.github.io.git public 
cd public\

After above commands, you will find README.md in public\folder.

Below is where magic happens. The command hugo -t contrast-hugo in the \Blog\blog\frankyudang\ foldergenerates static file into the \publicfolder.

cd .. # come back the \Blog\blog\frankyudang\ folder
hugo -t contrast-hugo # generate static file
cd public/ # heading to the folder to check out

Notice: After hugo -t contrast-hugo , the generated files will be in the \public folder

step 12 (IMPORTANT) what the below commands are doing is to push the gerenerated static assets into our static assets repository.

cd public
git remote -v # it will give you the repo link
git add . 
git commit -m "init commit" 
git push origin main

step 13 Almost done. Please go to the github repo website and you can see the update (Amazing!). And then check out the \setting\pages to view your site. It will take serval minutes to show as you design.

step 14. Done! now you can enjoy your artwork.

In summary. above is the procedure you will follow at the first time to build blog. Below is a summary of the key steps that you can repeat to add your own next post.
